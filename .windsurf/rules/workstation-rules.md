# Workstation Rules

## 1. Mode Awareness
Each workstation operates in one of two modes:

### NORMAL MODE
- Concise execution.
- Minimal explanation.
- Immediate output.

### ULTRATHINK MODE
- Activated only by explicit trigger.
- Deep, multi-dimensional reasoning required.
- Shallow logic is a failure condition.

## 2. Aesthetic Commitment
- A single aesthetic direction must be chosen before coding.
- Indecision is prohibited.

## 3. Typography Rules
- Generic fonts are banned.
- Typography must reinforce identity and tone.

## 4. Motion Discipline
- Motion must serve intent.
- One strong animation is preferred over many weak ones.

## 5. Code Quality
- Semantic HTML required.
- CSS variables mandatory.
- Redundant styles forbidden.
- Performance regressions are defects.
